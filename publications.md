# Publications

Edit this file to manage your publications. The build script (build.js) transforms this into publications.html.

Format for each entry:
- `type`: "conference" or "preprint"
- `title`: Paper title
- `authors`: Full author names, comma-separated. Put **bold** around your name.
- `venue`: VENUE YEAR (all caps for conference/journal name)
- `link_text`: Display text for the link
- `link_url`: URL to the paper
